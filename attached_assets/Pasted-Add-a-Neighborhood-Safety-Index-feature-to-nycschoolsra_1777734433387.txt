Add a Neighborhood Safety Index feature to nycschoolsratings.com.

Goal:
For every NYC school page, show a parent-friendly safety score based on public NYPD reported crime complaint data near the school.

Data sources:
- NYC Open Data / Socrata NYPD Complaint Data Current Year To Date dataset: 5uac-w243
- NYC Open Data / Socrata NYPD Complaint Data Historic dataset: qgea-i56i
- Existing school table should contain latitude and longitude. If not, use NYC School Point Locations / DOE school location data to enrich school coordinates.

Requirements:
1. Add a backend data sync job that fetches NYPD complaint data using the Socrata API.
2. Use an app token through environment variable SOCRATA_APP_TOKEN.
3. Store or cache crime data in Postgres. If PostGIS is available, use geography radius queries. If not, use Socrata within_circle queries and cache the results by school.
4. Calculate safety scores for radius values: 0.25 miles, 0.5 miles, 1 mile, and 5 miles.
5. Use 0.5 miles as the default.
6. Score should be 0–100, where higher means safer relative to other NYC school neighborhoods.
7. Compute:
   - total reported complaints
   - felony count
   - violent felony count where possible
   - misdemeanor count
   - violation count
   - top 3 offense categories
   - trend vs prior comparable period
   - citywide percentile across all schools
8. Add database table school_safety_index with:
   school_id, radius_meters, period_start, period_end, total_reports, felony_reports, misdemeanor_reports, violation_reports, violent_felony_reports, weighted_risk_score, safety_index, percentile_citywide, trend, last_calculated_at.
9. Add API endpoint:
   GET /api/schools/:schoolId/safety?radius=0.5
10. Add a frontend card on each school profile:
   - “Neighborhood Safety Index”
   - large 0–100 score
   - label: Excellent / Above Average / Average / Below Average / Elevated Activity
   - radius selector
   - trend indicator
   - top reported categories
   - last updated date
   - methodology disclosure.
11. Add a methodology page explaining that the score is based on reported NYPD complaint data near the school, not school-internal incidents and not a guarantee of safety.
12. Make the design clean, parent-friendly, and not alarmist.
